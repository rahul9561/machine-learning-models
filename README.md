## Machine Learning Models

This repository contains a curated collection of machine learning models implemented in Python.  
It covers fundamental to advanced techniques, including:

- ✅ Regression (Linear, Ridge, Lasso, etc.)
- ✅ Classification (Logistic Regression, SVM, Decision Trees, Random Forest)
- ✅ Clustering (K-Means, DBSCAN, Hierarchical)
- ✅ Dimensionality Reduction (PCA, t-SNE)
- ✅ Deep Learning (Neural Networks, CNNs using TensorFlow & PyTorch)

### 📌 Features
- Well-documented and beginner-friendly code
- Jupyter Notebooks with step-by-step explanations
- Real-world datasets for practice
- Optimized for easy experimentation and learning

### 🚀 Tech Stack
- Python | Scikit-learn | TensorFlow | PyTorch | Pandas | NumPy
